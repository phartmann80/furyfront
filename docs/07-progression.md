# Progression

Players go from **Level 1 to 125**, then **Prestige 1–10**. Prestige resets the visible level to 1 and keeps: weapons, attachments, operators, cosmetics, ranked rank.

Canonical curve: `data/xp-curve.json` generated by `xpForLevel` in `packages/shared`.

## Match XP

| Action | XP |
| --- | --- |
| Kill | 100 |
| Assist (≥ 30 dmg, not kill) | 50 |
| Headshot bonus | 10 |
| Objective (cap/plant/defuse/flag) | 75–200 |
| Win | 2500 |
| Loss | 1200 |
| Draw | 1600 |
| Scorestreak call-in | 25–80 |
| Survival (Arena, per phase) | 40 |

Multipliers: 2XP event ×2, Battle Pass boost ×1.25, Squad bonus ×1.10, first win of day ×1.5 (once). **Paid 2XP does not stack with event 2XP** (take max).

## Unlock cadence (account level)

| Band | Unlocks |
| --- | --- |
| 1–10 | Core AR/SMG/pistol, 2 operators, smoke/frag, UAV |
| 11–30 | Shotguns, LMG, Bishop–Wraith, airstrike, shop commons |
| 31–60 | Burst AR, snipers, Hex/Sable, juggernaut, ranked (lvl 20) |
| 61–90 | Launchers, remaining streaks, prestige cosmetics preview |
| 91–125 | Mastery calling cards, AMR-50, Holepunch, prestige ready |

Exact gates are in JSON (`unlockLevel` on each item).

## Prestige

| Prestige | Reward |
| --- | --- |
| 1 | Icon, 2% XP, exclusive emblem |
| 2–4 | Weapon charm, 2% XP each (additive) |
| 5 | Prestige KF-16 skin |
| 6–9 | Calling cards, finisher |
| 10 | Animated title “Front Legend”, 20% XP total |

Prestige is optional. Level 125 can idle.

## Daily / weekly missions

**Dailies (3):** 15 kills, 5 objective plays, 1 match win. ~1200 XP + 200 credits.  
**Weeklies (6):** class-specific (SMG kills), mode-specific, damage 5000, streak 5. ~4000 XP + 800 credits + 1 rare crate key (cosmetic).  
Reroll: 1 daily reroll free.

## Seasonal battle pass

- 11 weeks, **100 tiers**.
- Tier price: 10,000 XP per tier (catch-up: leftover XP banks 20% next season).
- Premium track: 1000 Fury Coins.
- Free track: ~18 items. Premium: ~90 cosmetic + 300 coins return (net 700).
- No paid skip beyond 20 tiers/week cap (anti-whale pressure on FOMO — skips allowed, 150 coins/tier).

See `data/battle-pass.json`.

## Ranked ranks

Bronze I–III → Silver → Gold → Platinum → Diamond → Master → **Fury**.  
Visible SR 0–100 per division. Decay: none until Diamond ( −2 SR/day inactive 7 d+).

## Weapon / operator levels

Independent tracks. Mastery camo: 100 headshots + 10 longshots + 5 bloodthirsties (5 kills one life) per weapon.
