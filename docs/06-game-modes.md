# Game Modes

**Zombie Horde is not a Fury Front mode.** Do not add undead, infected, or monster waves.

Shared future spawn logic: influence map — avoid LOS < 18 m. V0.1 uses scripted mission spawns.

## Shadow Assault / Base Defense (signature)

- 1–4 Fury Front operators vs Shadowbreaker AI (V0.1: 4 vs escalating AI).
- Defend installation, restore systems, stop intel theft, block extraction.
- Escalation: Phantom Infiltrators → Signal Hackers on objectives → Heavy Enforcers → optional elite commander.
- Fail if command integrity hits 0 or data extract completes.
- Maps: Ironfall Depot first; later any installation.

Prototype mission: **Operation: Broken Perimeter** (`docs/17-vertical-slice-01.md`).

## Future multiplayer

### Strikeout 5v5
Elimination rounds, limited lives, no zombie modifiers.

### Control Grid
Territory nodes (Domination-like). Own = score.

### Data Harvest
Move intel packets to upload. Shadowbreaker-themed even in PvP skins later.

### Team Deathmatch
Score 75 (6v6) / 100 (10v10). Time 10:00.

### Search & Destroy
2 sites, first to 4, no respawn.

### Domination
A/B/C flags, 200/250 points.

## DMZ: Recon Protocol

Obsidian Reef, Sector 9. Extraction PvEvP. Different armor rules than MP — **do not share one hard-coded plate model**.

## Battle Royale — Eclipse Zone

32–100 later. Not in V0.1.

## Ranked

Future. No purchased HP/damage/recoil/movement.

## Seasonal LTM

14-day cadence. Never “all guns unlocked permanently.”
